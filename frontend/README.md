# Фронтенд TV Poll

React-интерфейс формы голосования и админки. Перед запуском поднимите API из
`../backend`.

```bash
npm install
npm run dev
```

- форма зрителя: `http://localhost:5173/q/<id>`;
- админка: `http://localhost:5173/admin`;
- локальный токен: `dev-admin-token`.

Проверки:

```bash
npm run build
npm run lint
```
