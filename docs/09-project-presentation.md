# Сервис ТВ-опросов

### Голосование по QR-коду во время ТВ-эфира

Зритель голосует без регистрации. Администратор сразу видит результат.

---

# 2. Что умеет сервис

**Зритель**

- открывает ссылку по QR-коду;
- голосует без регистрации;
- не может случайно проголосовать дважды.

**Администратор**

- создаёт и запускает опрос;
- получает ссылку и QR-код;
- смотрит результат в реальном времени.

Главная сложность: много голосов приходит почти одновременно.

---

# 3. Как всё связано

```text
Зритель → API → Redis → PostgreSQL
```

- **API** проверяет запрос.
- **Redis** быстро считает голоса.
- **PostgreSQL** надёжно хранит историю.

Быстрая часть и надёжная часть не мешают друг другу.

---

# 4. Что происходит после нажатия

1. Проверяем, что опрос открыт.
2. Проверяем выбранный вариант.
3. Проверяем, не голосовал ли этот браузер.
4. Сохраняем голос и обновляем результат.

Новый голос принимается, повторный — отклоняется.

---

# 5. Демонстрация проекта

**Место для видео продолжительностью 60–90 секунд**

1. Администратор создаёт и публикует опрос.
2. Зритель переходит по QR и голосует.
3. Результат обновляется в реальном времени.
4. Повторный голос отклоняется.
